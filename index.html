For College/University projects, ENERGY STAR reports a U.S. median site EUI of 84.3 kBtu/ft²·yr. This is a national performance reference, not a city code limit.

For code compliance, use the jurisdiction's required prescriptive or performance path. If the performance path uses ASHRAE 90.1 Appendix G or an IECC performance method, the code baseline is a modeled reference building, not one universal EUI value.
